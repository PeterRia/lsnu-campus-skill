## 历史版本 1.2.0

本版增加 GitHub Actions 每小时采集官方通知，使用独立数据分支同步到本地公共缓存；新公告无需等待代码发版。每次新问题先同步，再调用独立的个人记忆 Skill，由当前 Agent 综合回答。

- 明确区分采集成功时间、通知发布日期与人工核查时间。来源失败保留上次成功信息，超过三小时标为过期。
- 公共采集仅处理官方标题、日期、URL、正文指纹与状态；个人记忆不进入 GitHub Actions、仓库或发布包。
- 旧安装使用新包重新导入；个人 Skill 和包外记忆继续保留。历史发布包不改名、不重写哈希。
- 80 项本地行为测试通过，新增通知发现、独立同步、内容变化、降级与时间真实性测试。

解压发布包后导入完整 `lsnu-campus-skill` 文件夹。详见 [使用文档](使用文档.md)、[采集与同步](../references/public-information.md) 与 [验证报告](验证报告.md)。

## 历史版本 1.1.0

本版仍为可供 Agent 安装的 Skill。首次使用创建独立的 `lsnu-personal-memory`；后续先检查公共更新，再按授权召回个人偏好、知识与可复用流程，由当前 Agent 生成个性化回答。

- 个人 Skill、私有存储和公共缓存分开，公共更新不覆盖用户定制。
- 记忆读取、保存、云端推理与公共贡献分别授权；有效授权内自动复用。
- 支持记忆修改、忘记、历史恢复、导出、暂停、撤销和关闭贡献提醒。
- 贡献需完整预览与具体批准，只提交待审核 issue；不确定回执不重复发布。
- 公共更新带逐文件允许清单、SHA-256、兼容性及路径检查，失败回退；个人辅助进程禁止联网。
- Python 3.10+ 标准库。隔离辅助工具当前适用于 macOS 和有可用 Bubblewrap 的 Linux；其他宿主提供公共离线资料，不能假称个人记忆已调用。

解压发布包，向支持文件夹 Skill 的 Agent 导入内层 `lsnu-campus-assistant` 文件夹。操作见 [使用文档](使用文档.md)，实际测试与未覆盖范围见 [验证报告](验证报告.md)。
