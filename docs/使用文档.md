# lsnu-campus-skill 使用文档

版本：1.2.1。资料核查日期：2026-09-23；功能更新日期：2026-09-24；采集维护日期：2026-10-20。

## 1. 你可以用它做什么

不需要学习命令，直接描述事情。例如：“我是 2025 级普通本科生，想办理本学期重修，给我具体步骤和截止。”

| 事情 | 能交付的结果 | 需要你提供 |
|---|---|---|
| 问校园规定、奖助与考试 | 条件、步骤、期限、官方来源与待确认项 | 影响适用性的身份／日期 |
| 排一周课表与任务 | 活动表、独立 DDL 清单、冲突与跨校区提示 | 时间、校区、地点 |
| 安排办证明等事情 | 在真实办理窗口内推荐备选时段 | 办理窗口、预计时长 |
| 核算学分 | 已认可学分、缺口、重复和待确认项 | 适用培养方案与脱敏已修记录 |
| 试讲、说课、答辩、面试 | 一轮一个问题，具体反馈与复盘 | 主题、目标、时长或材料 |
| 运动／学习周复盘 | 基于真实完成记录的统计与下一步 | 记录、完成状态和已知时长 |
| 新生查资料 | 可离线阅读的 Markdown 校园指南 | 年级、校区、关心的事情 |

目前不直接连接学校个人系统。因此不会自动知道你的成绩、课表、宿舍或座位余量；可以整理你提供的资料，并指出正规查询入口。

## 2. 在 Marvis 安装

下载 GitHub 仓库后解压，或使用发布包。进入含 `SKILL.md` 的文件夹，里面应同时有 `kb`、`references`、`scripts`，不要只拿出一个文件。

Marvis 的导入路径：

> 技能广场 → 工具箱 → 技能（Skill）→ 我的技能 → 导入技能 → 文件夹

选择该文件夹，完成导入后在“我的技能”确认能找到 `lsnu-campus-skill`／乐师校园助手。新建对话后选中它；也可明确说“请使用 `lsnu-campus-skill` Skill”。

其他支持文件夹 Skill 的 Agent 也可安装完整目录。宿主需能读取导入后的文件夹、执行本地工具并写入本地个人目录；运行工具需 **Python 3.10 或更新版本**，路径有空格时使用引号。macOS 默认 Python 可能过旧，助手应改用本机已有的兼容解释器。

个人记忆和公共更新辅助脚本目前支持 macOS，以及有可用 Bubblewrap 的 Linux。Windows 或仅支持提示词、不能运行脚本的宿主仍可阅读公共知识，但本版不提供其隔离记忆后端。不能把“识别到 Skill”当作所有功能已运行。

不需要注册知识库账号、配置向量数据库、安装分词库、设置 API key。联网查询由 Marvis 自带能力或本 Skill 的公开原页检查完成。

若导入后只识别到描述而读取不到知识卡，检查是否误用了“单个 .md”导入。重新以完整文件夹导入，并让助手说明实际安装目录。

首次提问时自动创建独立的 `lsnu-personal-memory`，下载 ZIP 本身不会执行初始化。每次新问题先检查程序版本并同步 Actions 公共快照，再调用个人 Skill。公开快照计划每天上午 10:00（UTC+8）采集一次，夜间不自动访问学校。GitHub 排队可能延迟；超过三小时的快照仍会提示过期，重要期限以官方原文为准。详见 [采集与同步](../references/public-information.md)。

从 1.2.0 或更早的旧标识迁移时，重新导入本版公共 Skill，保留 `lsnu-personal-memory` 与其 `local-config.json` 指向的记忆库。不要同时启用两个名称的公共副本；旧包可移到技能目录之外备份。

## 3. 先试这六句话

**问流程**

> 请用乐师校园助手查 2026 年秋季重修。我想知道报名截止、具体入口、课程匹配与缴费注意事项。请给官方出处，别把报名成功直接说成重修已经生效。

**分校区**

> 我准备在 2026 年 9 月 23 日去苏稽鼎堂图书馆自习和还书。哪些服务开放？请核对当日适用的官方通知。

**识别过期**

> 今天是 2026 年 9 月 23 日，我才想申请家庭经济困难认定。9 月 23 日这个节点是给学生还是给学院的？下一步应该怎么咨询？

**规划时间**

> 以下是虚构练习：周五 9:00—10:00 海棠上课，10:30—11:30 苏稽开会，11:00—12:00 还有一场活动，23:59 线上交论文。给我冲突和独立 DDL 清单；交通时间没依据就留待核实。

**试讲陪练**

> 我要面向大一学生做 15 分钟“信息可信度”试讲。先帮我明确一个可观察的学习目标，然后逐段陪我练；一次只提一个问题，等我回答再反馈。

**成长复盘**

> 以下是演示记录：9 月 14 日羽毛球 45 分钟、16 日慢跑 30 分钟、19 日羽毛球 60 分钟，均本人确认完成；20 日只预约了游泳没确认参加。请做这一周复盘，不把预约计入完成量。

## 4. 怎样得到更准确的回答

校园规定常受身份影响。只需补充与问题有关的信息：本科／研究生、入学年级、专业、普通／公费／专升本、校区、目标学期。不要主动发送账号密码、验证码、身份证或完整家庭材料。

回答中的来源应能点开。遇到“待核实”表示还缺证据，不表示学校不允许。遇到较旧流程，助手应告诉你其年份，并给当前核实路径。

需要办事时，要求同时列出**学生截止、学院截止、材料、入口、成功凭据**。需要当前金额、实时名额或校车时刻时，让它核查最新原页；不能联网时只应给离线依据。

## 5. 个人数据与保存

首次使用校园 Skill 时，先检查公共版本，再自动建立独立的 `lsnu-personal-memory` Skill。后续每次使用都会调用它，在有效授权范围内召回相关偏好、个人知识和做事方法，由当前 Agent 综合回答。操作均在现有 Agent 对话中完成。

可直接说：“记住我希望先给结论，再列下一步”“把我的校区改成苏稽”“忘记这条偏好”“以后办理校园事项先区分学生与学院的截止时间”。这些个人规则保存在包外，不会写回共享校园 Skill。

首次读取需要明确允许的记忆类别、宿主与期限；如果宿主使用云端模型，还需明确允许这些召回内容用于其推理。已有有效授权内自动复用，不反复询问。你也可以一直只使用公共知识。保存记忆、读取记忆、云端推理、公开贡献分别授权；同意其中一项不代表全部同意。

个人记忆默认放在用户本地 `.local/share/lsnu-personal-memory/`。公共更新不覆盖个人 Skill、记忆、个人流程或授权。支持查看、修改、导出、忘记、暂停和撤销；可说“关闭贡献提醒”。具体调用约定见 [个人记忆与共享更新](../references/personalization.md)。

默认可以只在对话中处理。希望长期维护时，指定自己的包外目录，例如“文稿／我的乐师计划”；不要把真实数据放进下载的 GitHub 仓库。

建议分成：

```text
我的乐师计划/
  课表与事项.json
  成长记录.json
  学分核对.json
  输出/
    每周计划.md
    试讲复盘.md
```

由助手根据自然语言整理 JSON，再运行工具；你不必手写。示例文件都有“虚构”标记，不能直接当个人记录。修改／取消具体事项先明确哪条，保留旧版，重新检查受影响的日程。

## 6. 导出日历

让助手“生成 ICS 文件”，会得到可导入的日程草稿；不等于已经写入日历。

固定课程和活动用日历事件，DDL 用待办。部分日历不支持导入待办，导入后检查截止清单是否完整；有缺失时保留 Markdown 清单，或者明确让助手按你选定的时间生成提前提醒事件。

默认没有提醒铃声。需要提醒时说出“提前多久”并确认日期；官方只写“某日前”时，精确提醒时刻应作为你自己的提前安排，不能写成学校明确规定的时刻。

## 7. 开发者命令

以下均在 Skill 根目录运行，输入文件可用绝对路径：

```bash
# 安装与语料一致性
python3 scripts/companion.py start
python3 scripts/campus.py doctor
python3 scripts/maintain.py check

# 检索与回读
python3 scripts/campus.py search "重修报名" --as-of 2026-09-23 --top 5
python3 scripts/campus.py show retake-2026-autumn

# 当次读取公开原页，不自动改写知识卡
python3 scripts/campus.py check-sources --id retake-2026-autumn

# 运行明确标注的虚构示例
python3 scripts/planner.py examples/plan-demo.json
python3 scripts/credits.py examples/credits-demo.json
python3 scripts/progress.py examples/progress-demo.json --start 2026-09-14 --end 2026-09-20
```

保存计划到包外目录：

```bash
python3 scripts/planner.py "/你的数据目录/课表与事项.json" \
  --output "/你的数据目录/输出/计划.json" \
  --ics "/你的数据目录/输出/计划.ics"
```

输入规范见 [日程说明](../references/planning.md)、[学业说明](../references/academic.md)、[成长说明](../references/life-and-growth.md)。脚本报错会返回非零退出码和错误说明；没有匹配的知识查询返回 `no_match`，两者不能混为一谈。

## 8. 覆盖与局限

本版有 19 张人工核对卡，重点是当前能用的办事与校园服务，不按材料数量冒充全面性。不同主题可能共享一份官方章程，因此“19 卡”不等于 19 份独立制度。

已核对正文：2026 秋季开学、2026 本科招生章程、当期重修、四六级、国家奖助、校长奖学金、困难认定、苏稽图书馆阶段开放等；另保存带年份限制的旧办理指南和官方导航。2026—2027 校历 PDF 已下载并视觉核对。

尚未读到全文：下载需验证码的新版作息、转专业管理办法、学位细则、三字一话等附件。包内只给已核实的索引或其他正文能支持的概述；不会猜合格线、资格限制或节次时间。

缺实时接口：个人教务、余座／考位、校车、宿舍、实时场馆预订。用户登录官方页面后可继续在宿主授权范围内操作，但本包没有宣称这些集成已经实现。

脚本检查输入数据，不能判断所有未给出的校园限制。模型仍可能误读，因此关键日期、金额、资格要回看引用原页。测试结果和未覆盖事项见 [验证报告](验证报告.md)。

## 9. 更新与开源贡献

每次独立调用首先检查固定可信上游；新版本通过来源、文件完整性、兼容性和权限检查后，自动切换公共版本。断网或校验失败时使用可用的本地资料，并如实说明未完成核验。版本更新不代表学校政策必然仍有效。

遇到有官方出处的公共修正时，助手可以适度邀请贡献。先展示拟提交的完整内容、公开仓库和身份，由你针对该内容明确批准后才提交待审核 issue。拒绝不影响使用；本地记忆不自动上传。没有用户批准，不会把聊天、整个记忆库或个人文件附带提交。

你可以通过 GitHub issue 提供“问题、官方链接、适用日期、预期行为”，避免贴个人材料。修改知识卡后按 [贡献指南](../CONTRIBUTING.md) 更新元数据、校验和与验证记录。

优先补齐与真实需求相关的新证据：新版作息、制度附件、各专业培养方案、校车和办事位置。每增加一项，至少用一个实际问题验证；不只往介绍里增加功能名称。
