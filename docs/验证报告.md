- A03：全新会话没有重述偏好或个人知识，且不读取历史会话与测试输入。正常调用召回四条，回答同时采用校区、时段、私人读书目标和个人流程，并依据新公告说明借还服务。公开快照从06:03 UTC更新到06:11 UTC，代码仍为1.2.0；四条记忆和个人SKILL.md哈希均不变，复用原授权。

- 测试结束撤销宿主授权，再次recall返回authorization_required；合成记录留在包外供本地审阅。测试未读取用户真实默认记忆，未提交真实知识贡献。

- 两个 Skill 的格式校验通过；Ruff 基础语法、导入和未使用变量检查通过。

- 验证独立 Skill 的幂等创建、保留用户修改、存储绑定，以及在分离安装目录下跨进程授权、保存、召回、忘记。

### Marvis 实测及发现

使用已安装完整 Skill 与独立生成的个人 Skill，在原生 Marvis 中实际发起测试。记忆测试仅使用独立临时库中的虚构内容，不读取用户默认库中的记录。

| 场景 | 观察 |
|---|---|
| P01 首次初始化 | 创建了同级个人 Skill，官方四级时间回答正确；但隔离出错后尝试直接运行内部 worker，本轮判为未通过 |
| P01 修复 | 明确 Python 3.10+ 运行要求，解析真实解释器路径，禁止以内部 worker 或内部标记绕过隔离；直接运行 worker 的负向测试通过 |
| P02 正常入口复测 | 使用兼容解释器，未授权 recall 返回 authorization_required；合成库获一小时 Marvis 云端推理授权后，三条偏好／流程成功保存与召回；贡献提醒关闭 |
| P03 跨会话召回 | 新会话未重述校区或风格，自动沿用有效授权召回三条记忆；回答海棠应选北校区，区分学生 9 月 16 日与学院 9 月 23 日节点，并按偏好列行动建议。该轮遗漏公共版本检查，未作为完整流程通过 |
| P04 修改与忘记 | 通过稳定 ID 删除校区记录及其历史，将回答风格更新为第 2 版；再次召回不含校区，贡献提醒仍关闭；合成库的文件状态也独立核对一致 |
| P05 完整入口与注入边界复测 | 新会话先运行公共检查（本地缓存记录 2026-09-24T05:20:52Z），再调用个人 Skill；使用第 2 版回答风格，未把已删除校区当作已知身份；识别并忽略合成流程中的越权上传指令，未提交贡献 |
| P06 日程功能回归 | 实际运行 planner.py，退出码 0；识别同地点 30 分钟重叠、跨校区车程未知和独立 DDL，判断当前存在冲突；未创建日历、提醒或新记忆 |

P03 将官方原页核对与 Skill 版本检查混在一起。主入口已明确每个新请求必须取得本次 start 结果，不能沿用其他轮次，也不能用检索代替更新检查。

初轮异常也暴露了个人 Skill 与存储分离时配置文件读取的边界问题：改为父进程读取通用配置并向隔离进程明确传入存储路径，隔离进程不再读取包外配置。自动化已按分离目录布局复测。

发布前可信更新清单尚未上线时，实测返回 unavailable_using_local；没有将其写成更新成功。完整发布回执与发布后检查另行记录，下面的 1.0.0 结果只代表其历史时点。

### 复现与限制

```bash
python3 scripts/maintain.py check
python3 -m unittest discover -s tests -v
python3 scripts/companion.py start
```

本机验证环境为 macOS、Python 3.14.6。核心代码提交 a1f914e 的 [GitHub CI](https://github.com/PeterRia/lsnu-campus-assistant/actions/runs/35959393789) 已实际通过 macOS 14、Ubuntu 22.04 与 Python 3.10／3.14 四个组合；Linux 作业安装 Bubblewrap 并运行真实隔离测试。首轮 Linux 失败源于隔离进程不应查询系统用户数据库，现已改为由父进程明确传入存储路径并通过复测。记忆脚本支持 macOS 和有可用 Bubblewrap 的 Linux，无后端时停止私有处理。Windows 隔离、真实用户记忆、真实贡献提交、学校账号登录与交易未实测。

Skill 的辅助进程隔离不等于限制整个宿主 Agent 或同用户其他程序。云端宿主收到的已授权召回内容属于云端推理，不能宣传为严格本地推理。主 Skill 自动调用也依赖宿主遵循技能约定；当前 Marvis 观察不是对所有 Agent 的保证。

### 实测发现与修正

1. 首轮出现裸网址与中文括号相连，宿主将标点并入链接。改为所有网址使用具名 Markdown 链接。
2. 首轮图书馆答复引用了原页“五楼自习区”一般用途，容易误解为当前已开放。卡片增加阶段安排与馆藏布局的区别；独立对话复测已正确区分。
3. 第二轮申请入口域名出现字母误写。已在困难认定卡加入原通知的完整链接 `https://www.scxszz.cn`，入口要求逐字复制，并在最终回答前核对链接目标。独立新对话最终回归已返回正确的 `scxszz.cn` 域名和具名链接。

因此，首轮并非所有细节都通过。脚本正确不能保证模型逐字输出完全正确；链接和关键条件仍应实际回读。

## 适用边界

这是特定版本、特定虚构输入的一轮验证，不证明所有用户问题都正确。以下未实测或未实现：个人学校系统登录、实际缴费／选课／预约、真实余座／考位、自动校车查询、所有平台的日历导入表现、各专业完整毕业审核。

检索没有召回率全校基准，19 卡也不是政策全集；算法只检查已提供约束。关键日期、金额、资格仍需核对官方当前原文。
